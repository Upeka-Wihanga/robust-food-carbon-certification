# Roadmap

## Completed repository milestone

- initialize Git and the Python project scaffold;
- verify all handoff hashes and byte lengths;
- archive supplied frozen evidence without modifying it;
- manifest raw datasets without duplicating or committing them;
- document PoC evidence, missing artifacts, scope, and known issues.

## Next reconstruction phases

1. Reconstruct the robust certification core from frozen evidence, beginning
   with the historical false-certificate fixture and independent reference
   checks.
2. Reconstruct the QUID inverse and uncertainty interpolation with permanent
   threshold and midpoint regressions.
3. Recover FCID, dataFIELD, and Guan inclusion/mapping rules before rebuilding
   derived panels.
4. Reconstruct leakage-free policies and dependence-aware evaluation.
5. Reproduce recoverable Stage-20, Stage-22, and Stage-24 metrics, clearly
   labelling any irrecoverable result.

Each phase should be one or more small commits that do not combine behavioral
reconstruction with unrelated refactoring.

## Active research work

The following remain incomplete and must not be represented as finished:

- observation-aware sequential acquisition;
- genuinely held-out sequential evaluation;
- realistic observation models;
- strong decision-aware acquisition baselines;
- stronger acquisition-cost justification;
- broader real-world and commercial external validation;
- final production-quality application and interface.
